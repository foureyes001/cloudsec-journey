## Design snapshot (as of v3)

- **Question:** can AWS CloudTrail logs alone tell an AI agent, a script and a human apart by *behaviour*, without relying on metadata?
- **Central pair: agent vs script.** A boto3 agent and a boto3 script produce identical `userAgent` strings, so metadata can't separate them.
- **Tasks:** 12 hooked audit tasks + 1 control (T13). 8 hook types, 36 placements.
- **Features:** 7 families. Evaluated across a metadata-removal ladder **L0–L3**, ordered by adversary cost.
- **Scale:** 3 models; ~117 agent · 39–78 script · 43 human sessions; group-aware evaluation splits.
- **Modules piloted:** Module 1, script generation (T1, 4 models; generated and read, never executed) · Module 2, task probe (below).
